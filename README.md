# Papakha — сайт кофейни

Одностраничный сайт кофейни Papakha (Махачкала, ул. Буйнакского, 6): меню с поиском, фото, часы работы и карта.

- `index.html` — разметка
- `styles.css` — стили
- `app.js` — логика (меню, поиск, статус «открыто», галерея)
- `menu.js` — данные меню: здесь меняются позиции и цены
- `img/` — локальные изображения

Сайт статический, сборка не нужна. Локально: `python -m http.server` в папке проекта.
